# Tài liệu Slide Bảo Vệ — Đèn Hoa Mỹ

Bộ tài liệu hỗ trợ làm PowerPoint/Google Slides cho buổi bảo vệ đồ án (38 slide + appendix).

## File chính

| File | Mục đích |
|------|----------|
| [SLIDE_OUTLINE.md](SLIDE_OUTLINE.md) | **Nội dung copy-paste** cho 38 slide |
| [SLIDE_DIAGRAMS.md](SLIDE_DIAGRAMS.md) | 12 sơ đồ Mermaid — export PNG cho slide |
| [SLIDE_SCREENSHOTS.md](SLIDE_SCREENSHOTS.md) | Checklist 10 screenshot cần chụp |
| [DEMO_SCRIPT.md](DEMO_SCRIPT.md) | Kịch bản demo live 5–7 phút |
| [SLIDE_APPENDIX_QA.md](SLIDE_APPENDIX_QA.md) | 5 slide appendix + câu trả lời hội đồng |

## Thư mục assets

Lưu screenshot tại `assets/` (xem [SLIDE_SCREENSHOTS.md](SLIDE_SCREENSHOTS.md)).

## Quy trình làm slide

1. Đọc [SLIDE_OUTLINE.md](SLIDE_OUTLINE.md) — tạo 38 slide PowerPoint
2. Export sơ đồ từ [SLIDE_DIAGRAMS.md](SLIDE_DIAGRAMS.md) qua [mermaid.live](https://mermaid.live)
3. Chụp screenshot theo [SLIDE_SCREENSHOTS.md](SLIDE_SCREENSHOTS.md) → `assets/`
4. Rehearse demo theo [DEMO_SCRIPT.md](DEMO_SCRIPT.md)
5. Thêm slide A1–A5 từ [SLIDE_APPENDIX_QA.md](SLIDE_APPENDIX_QA.md) (ẩn sau slide 38)
